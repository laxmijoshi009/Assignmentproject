# Design Choices — Module 6: Box Model & Positioning I created a styled multi-page student website using HTML and CSS. The website includes Home, About, Registration, and Contact pages linked through a common navigation bar. I selected navy blue, teal, white, and light grey to give the website a clean and professional appearance. Arial is used as the main font for readability. The CSS box model is demonstrated using margin, padding, border, and `box-sizing: border-box`. Content cards have rounded corners and suitable spacing. The navigation bar uses `position: sticky` to remain visible at the top while scrolling. Media queries help the website adapt to smaller screens. A shared CSS stylesheet maintains a consistent design across all pages and makes the project easier to update.
