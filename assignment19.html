Purpose of the Meta Tags Audit

Metadata in the document <head> provides essential information to browsers, web crawlers, search engines (SEO), and social sharing platforms. This assignment validates each critical tag and documents its implementation status.

Metadata Audit Checklist

Tag / Attribute Sample Value Primary Purpose Status
<meta charset> UTF-8 Enables universal character encoding for international text and symbols. Passed
<meta name="viewport"> width=device-width, initial-scale=1.0 Establishes the mobile viewport width to prevent unwanted scaling on smartphones. Passed
<meta name="description"> Portfolio of laxmijoshi009... Displays the concise summary snippet below search engine result links. Passed
<meta property="og:title"> Manisha Tiwari – Student Portfolio Defines the bold title in social media card previews (LinkedIn, WhatsApp, etc.). Passed
<meta property="og:image"> Invertis University Banner URL Supplies the visual thumbnail attached to link shares. Passed
<meta name="twitter:card"> summary_large_image Directs X/Twitter to render an expansive high-resolution preview card. Passed
<link rel="canonical"> https://github.com/laxmijoshi009 Prevents duplicate content penalties by designating the authoritative page URL. Passed
